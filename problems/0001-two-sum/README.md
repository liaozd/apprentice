# 1. 两数之和(Two Sum)

- 链接: <https://leetcode.cn/problems/two-sum/description/>
- 难度: Easy
- 标签: 数组 / 哈希表
- 状态: ⬜ 未开始(⬜ 未开始 / 🔨 进行中 / ✅ 已通过 / 🔁 重刷)

## 题意

给定整数数组 `nums` 和目标值 `target`,返回两个不同下标 `i, j` 使得
`nums[i] + nums[j] == target`。每个输入恰好有一个解,不能使用同一元素两次,
返回下标顺序不限。

## 思路

| 解法 | 核心想法 | 时间 | 空间 | 文件 |
|------|----------|------|------|------|
| 暴力枚举 | 双重循环枚举所有数对 | O(n²) | O(1) | [brute_force.py](brute_force.py) |
| 哈希表 | 边遍历边存 `值→下标`,查 `target - 当前值` | O(n) | O(n) | [hash_map.py](hash_map.py) |

### 关键点 / 坑(动手前先读)
- [ ] 不能用同一元素两次:先查哈希表再插入当前值,或插入前确认查到的下标 ≠ 当前下标
- [ ] `nums` 不保证有序 → 两指针法不适用(那是 167. 两数之和 II 的题)
- [ ] 返回的是下标,不是数值本身

# 200. 岛屿数量(Number of Islands)

- 链接: <https://leetcode.cn/problems/number-of-islands/description/>
- 难度: Medium
- 标签: 深度优先搜索 · 广度优先搜索 · 并查集 · 矩阵
- 状态: 🔨 进行中

## 题意

`m × n` 二维网格,`'1'` 是陆地、`'0'` 是水,计算岛屿数量。
岛屿被水包围,陆地按水平/垂直方向连通(对角不算)。

- 约束:`1 <= m, n <= 300`,网格仅含 `'0'`/`'1'`。

## 思路(三种经典解法)

| 解法 | 核心想法 | 时间 | 空间 | 文件 |
|------|----------|------|------|------|
| DFS 染色 | 遇到 `'1'` 计数 +1,DFS 把整块陆地"沉岛"成 `'0'` | O(m·n) | O(m·n) 递归栈 | [dfs.py](dfs.py) |
| BFS | 同样染色,用队列层序扩展,无递归爆栈风险 | O(m·n) | O(min(m,n)) 队列 | [bfs.py](bfs.py) |
| 并查集 | 相邻陆地 `union`,最后数不同根 | O(m·n·α) | O(m·n) | [union_find.py](union_find.py) |

### 关键点 / 坑(动手前先读)

- [ ] 标记(沉岛/visited)要在**递归或入队之前**做,否则同一格被重复处理
- [ ] Python 递归 DFS:全陆地 300×300 时递归深度可达 ~9 万,默认上限 1000 直接 `RecursionError` —— 改显式栈/队列,或 `sys.setrecursionlimit`
- [ ] BFS 必须**入队时标记**,出队时才标记会重复入队,网格大时超时
- [ ] 并查集:find 时路径压缩;`'0'` 不建节点(或用哨兵统一代表水)
